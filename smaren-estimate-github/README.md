# スマレン 仮見積もり

スマレン（https://www.smart-banner-rental.com/）のレンタル什器を選ぶと、7日間のレンタル料金・印刷メディア・デポジットの目安が出る計算機です。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `index.html` | 画面と計算のしくみ |
| `products.json` | 価格・在庫・デポジット・印刷費（ここを書き換えます） |
| `images/` | 商品の写真 |

## 価格・在庫を変えるとき

1. GitHubで `products.json` を開き、右上の鉛筆マークを押す
2. 数字を書き換える（例：`"stock": 1` を `"stock": 2` に）
3. 下の「Commit changes」を押す
4. 1〜2分でサイトに反映されます

- 決まっていない金額は `null` と書きます（印刷費が `null` だと「要見積もり」と表示）
- 在庫を `0` にすると「在庫なし」になり選べなくなります
- `"` や `,` を消すと読み込めなくなるので注意してください

## 写真を入れるとき

`images` フォルダに、商品ごとに決まった名前で写真を置きます（例：`flextile80.jpg`）。
名前の一覧は `products.json` の `"image"` の行に書いてあります。写真がない商品は「写真準備中」と表示されます。
